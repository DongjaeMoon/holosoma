실제 커맨드 분포 · 정규화 이전 / 이후

vx · vy · yaw 각각의 분포를 선으로 비교합니다. 왼쪽은 raw command, 오른쪽은 학습 당시 실제 기록된 normalized command입니다.

전체 통계 대시보드비율 그래프 PNGSVG확률밀도 PNG곡선 데이터 CSV

실제 CSV에 남긴 env 0 표본을 사용합니다. 같은 명령이 유지된 매 timestep을 각각 셉니다. Gaussian/KDE 스무딩 없이 구간별 비율·밀도를 선으로 연결하므로, 오른쪽 raw vy 표본을 인위적으로 만들지 않습니다. 0 명령이 많아 뾰족한 봉우리가 생길 수 있습니다.

정규화 후 가로축은 속도의 물리 단위가 없는 정규화 값입니다. 이후 분포는 고정 체크포인트 통계로 다시 계산한 값이 아니라 CSV의 normalized_vx / normalized_vy / normalized_yaw 그대로입니다. 확률밀도는 비율을 구간 폭으로 나눈 값으로, 각 구간의 밀도×폭을 더하면 1입니다.
