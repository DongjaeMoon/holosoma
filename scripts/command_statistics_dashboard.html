같은 정규화 통계로 왼쪽과 오른쪽을 비교하면?

env 0에서 기록한 raw vy들을 선택한 체크포인트의 고정 통계로 다시 변환한 분포입니다. 위의 ‘학습 당시 실제 normalized_vy 분포’와 구별하세요.
